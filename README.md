### About me

Self-taught full-stack developer based in Nigeria. I build and ship production web products end-to-end — frontend, backend, payments, auth — for real users, not just portfolio pieces. I run a small dev agency (Axion Digital) alongside my own SaaS projects, and I'm currently sharpening up for a junior frontend/full-stack role.

**[OrbitCV](https://orbitcv.vercel.app)** — AI resume-builder SaaS. React + Vite frontend, Supabase (auth, DB, RLS), Paystack subscriptions (monthly Pro plan + pay-per-unlock), OpenAI-powered resume scoring, deployed on Vercel.
`React` `Supabase` `Paystack` `OpenAI API` `TanStack Query`

**Resume Score API** — A standalone public API I built to properly learn API design: input validation, OpenAI integration, structured JSON responses.

**Youth For Christ Verse App** — Daily-verse web app built for my church youth ministry. Supabase backend, transactional email via Resend, deployed on Vercel.

`HTML/CSS/JS` `SEO` `Automation`

### How I use AI in my workflow

I treat AI tools (Claude, OpenAI models) as part of my dev process, not a crutch:
- Architecture decisions and debugging on real production bugs (auth race conditions, RLS leaks, cache issues)
- Shipping AI features inside products themselves — OrbitCV's resume scoring and the Resume Score API both run on the OpenAI API
- Faster iteration on unfamiliar stacks (FastAPI, Flutter) while still writing and understanding the code myself
